# Exact identity evidence, never heuristics

Maestro binds a session to a surface only through exact session UUID, workspace and surface UUIDs, process ancestry, and generation. It never uses titles, paths, focus, chronology, transcript text, or names. Missing, stale, ambiguous, or replaced evidence stays unknown.

Why: a wrong guess shows one agent's state on another agent's row and can aim a close or message at the wrong terminal. A visible "unknown" is cheaper than a confident lie.

Rejected: title and transcript heuristics, last-focused surface, reusing a surface's previous owner.

Consequence: more rows show unknown or partial. Rerouted bindings drop out instead of showing stale identity.
