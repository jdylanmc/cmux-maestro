# Taskboard is sidebar-only

The Taskboard lives in the sidebar as one card per agent session, bucketed by state. Content tabs were deleted. Taskboard shows sessions only; sub-agent, skill, shell, and internal-task rows stay in Hierarchy. Selecting a card focuses its terminal.

Why: one place to look. Content tabs duplicated the sidebar and the host gives the extension no content surface to own.

Rejected: a content-tab Taskboard.

Consequence: Taskboard width is the sidebar's width. Layout work must fit narrow columns.
