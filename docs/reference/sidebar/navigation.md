# Navigation and ended rows

[↑ Sidebar presentation](../sidebar-presentation.md) | [← Managed Git context and notices](managed-git-context.md) | [Refresh and render cost →](refresh-cost.md)

Unresolved child rows navigate to their owning session's exact terminal even
when its session heading is suppressed by a managed row. Navigation validates
the session, child, captured placement and current host topology separately
from Details eligibility. Unavailable focus targets render static titles;
targets invalidated after capture report the existing stale-target footer.
An exactly verified in-process replacement's current children can navigate:
the retained, positively replaced observation is not a conflicting occupant.
Unverified or protected previous sessions still prevent ambiguous navigation.
No guessed ancestry, surface or replacement-session navigation.

Managed primary clicks and **Focus surface** validate the captured node, run,
session, generation and exact CMUX placement independently of Details access.
They never substitute another session or a moved/recreated surface. A missing
surface disables focus; a captured action invalidated before invocation reports
stale navigation, not a Details popover.

With current, complete observation access, an existing terminal reverts to its normal
terminal row when its managed process is verified ended (controller process
disappearance, exact dead-session observation, or generation-matched exited
process evidence), with no live or uncertain observed occupant and **Show ended
agents** off. Undismissed failures, reported blockers, blocking/error attention,
failed/blocked or internal tasks, and degraded or omitted child evidence prevent reversion.
Dead-process liveness alone is not incomplete evidence.
Global partial observations retain exact managed history, not unrelated clean
unmanaged ended rows. Those still follow **Show ended agents**.
History/attention storage failures keep ended rows visible. Only presentation
changes: retained nodes, generations, history, capacity and live descendants stay
untouched. Missing surfaces keep the existing **Show ended agents** policy.
